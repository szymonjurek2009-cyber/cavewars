# Szablony światów CaveWars

Archiwa ZIP zawierają oryginalne szablony światów aren z serwera (pliki `level.dat`, `paper-world.yml`, `data/` i `region/`). Wykluczono `session.lock`, kopie `level.dat_old` i ewentualne dane graczy. Pliki `paper-world.yml` są także dostępne obok archiwów.

Aby odtworzyć szablon, rozpakuj wybrane archiwum do `plugins/CaveWarsWorlds/templates/<nazwa>/` na wyłączonym serwerze. Nie zastępuj działającego świata bez kopii zapasowej.

Pliki ZIP są artefaktami; nie edytuj ich tekstowo.
